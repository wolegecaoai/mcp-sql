## 三、当前项目形态

- **分层契约**：`Tools`（参数校验 + 中文文案 + 审计埋点）→ `Services`（守卫、路由、结果归一化）→ `Providers`（**唯一**生成方言 SQL 的地方，四类库各一份）。
- **14 个工具**：
  - 只读 12 个：`list_databases`、`list_tables`、`describe_table`、`list_indexes`、`list_views`、`list_stored_procedures`、`test_connection`、`health_check`、`table_exists`、`execute_query`、`export_query_result`、`query_audit_log`；
  - 写 2 个：`execute_non_query`、`execute_ddl`（均 confirm 二次确认）。
- **两条传输**：`stdio`（客户端拉起进程，日志走 stderr）/ `http`（监听 `0.0.0.0:<HttpPort>`，端点为 `/mcp`，ApiKey 为空时一律 401）。
- **安全不变量**：写操作两阶段（演练回滚 / 确认提交）、剥离注释与字面量后匹配黑名单、CTE 穿透识别主语句、`SELECT ... INTO` 按写拦截、例程/触发器创建整体拒绝、MySQL DDL 不可演练走 fail-closed、CSV/XLSX 公式注入防护、审计只落 SQL 哈希与前 200 字符。
- **测试结构**：23 个测试文件、209 个 `[Fact]/[Theory]` 方法（表驱动展开后 364 项）；集成测试由 `Category!=Integration` 默认排除，缺环境变量时报错而非静默跳过。

## 四、注意事项

1. **`main` 落后 3 个提交**：最后一个基线是 `6897013`，之后的 HTTP 传输、审查修复、M1 脱敏仅存在于 feature 分支。
2. **无 tag**：`release.yml` 未被触发过；推首个 `v*` 标签前，先确认发布产物的凭据守护检查（内网地址 / 8 位以上数字串）可通过。
3. **`publish/` 与 `bin/` 中的 `appsettings.json` 是拷贝**：配置文件改动只对「重新 publish / 重新 build 之后」的副本生效；`http` 模式下若直接从这些目录启动，会读到不含 `Transport` 的旧副本而回退为 stdio。
4. **`appsettings.json` 不入库**：仓库仅跟踪 `appsettings.example.json`；`.gitignore` 已用 `appsettings*.json` + `!appsettings.example.json` 挡住各类配置副本。
